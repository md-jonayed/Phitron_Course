27. as we have displayed our form to user now we need to store the user inputs which will be collected through forms. we need to validate our form through post method and save the informations into our databases. Then redirect to our home page/in the form page. All these are done though our views.py of our app. 

Example code views.py:

from django.shortcuts import render, redirect
from .import forms
# Create your views here.


def add_musician(request):
    if request.method == "POST":
        musician_form = forms.MusicianForm(request.POST)
        if musician_form.is_valid():
            musician_form.save()
            return redirect('home')
    else:
        musician_form = forms.MusicianForm()
    return render(request, 'add_musician.html', context={'form': musician_form})
